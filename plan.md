## 2. Database Schema (Drizzle + Supabase)

> All tables use **uuid** PKs (Supabase default), **timestamps**, and soft-delete via `deleted_at`.

### 2.1 `users`

| Column          | Type                     | Notes                          |
| --------------- | ------------------------ | ------------------------------ |
| id              | uuid PK default random   |                                |
| name            | varchar(255) NOT NULL    |                                |
| email           | varchar(255) UNIQUE NN   |                                |
| password_hash   | text NOT NULL            | bcrypt                         |
| role            | enum('manager','staff')  | default 'staff'                |
| is_active       | boolean default true     |                                |
| created_at      | timestamp default now()  |                                |
| updated_at      | timestamp default now()  |                                |

### 2.2 `otp_codes`

| Column      | Type                    | Notes                            |
| ----------- | ----------------------- | -------------------------------- |
| id          | uuid PK                 |                                  |
| user_id     | uuid FK → users         |                                  |
| code        | varchar(6) NN           | 6-digit OTP                      |
| expires_at  | timestamp NN            | now + 10 min                     |
| used        | boolean default false   |                                  |
| created_at  | timestamp default now() |                                  |

### 2.3 `categories`

| Column      | Type                    | Notes              |
| ----------- | ----------------------- | ------------------ |
| id          | uuid PK                 |                    |
| name        | varchar(255) UNIQUE NN  |                    |
| description | text                    |                    |
| created_at  | timestamp default now() |                    |

### 2.4 `warehouses`

| Column      | Type                    | Notes                  |
| ----------- | ----------------------- | ---------------------- |
| id          | uuid PK                 |                        |
| name        | varchar(255) UNIQUE NN  |                        |
| address     | text                    |                        |
| is_active   | boolean default true    |                        |
| created_at  | timestamp default now() |                        |

### 2.5 `locations`

Locations sit inside warehouses (e.g. "Rack A", "Production Floor").

| Column        | Type                    | Notes                  |
| ------------- | ----------------------- | ---------------------- |
| id            | uuid PK                 |                        |
| warehouse_id  | uuid FK → warehouses    |                        |
| name          | varchar(255) NN         | e.g. "Rack A"         |
| type          | enum('internal','customer','supplier','adjustment') | default 'internal' |
| created_at    | timestamp default now() |                        |

**Unique**: (warehouse_id, name)

### 2.6 `products`

| Column            | Type                    | Notes                       |
| ----------------- | ----------------------- | --------------------------- |
| id                | uuid PK                 |                             |
| name              | varchar(255) NN         |                             |
| sku               | varchar(100) UNIQUE NN  |                             |
| category_id       | uuid FK → categories    | nullable                    |
| unit_of_measure   | varchar(50) NN          | e.g. "kg", "pcs", "litre"  |
| description       | text                    |                             |
| image_url         | text                    |                             |
| reorder_point     | integer default 0       | low-stock threshold         |
| reorder_qty       | integer default 0       | suggested reorder quantity  |
| created_at        | timestamp default now() |                             |
| updated_at        | timestamp default now() |                             |

### 2.7 `stock_levels`

Tracks **current** quantity of a product at a specific location. One row per (product, location).

| Column       | Type                    | Notes                      |
| ------------ | ----------------------- | -------------------------- |
| id           | uuid PK                 |                            |
| product_id   | uuid FK → products      |                            |
| location_id  | uuid FK → locations     |                            |
| quantity     | integer NN default 0    | current on-hand qty        |
| updated_at   | timestamp default now() |                            |

**Unique**: (product_id, location_id)

### 2.8 `operations`

A single table for **all** operation types: receipt, delivery, internal transfer, adjustment.

| Column             | Type                    | Notes                                               |
| ------------------ | ----------------------- | --------------------------------------------------- |
| id                 | uuid PK                 |                                                     |
| reference          | varchar(50) UNIQUE NN   | auto-generated e.g. "REC-000012"                    |
| type               | enum('receipt','delivery','internal','adjustment') |                                    |
| status             | enum('draft','waiting','ready','done','cancelled') | default 'draft'                   |
| source_location_id | uuid FK → locations     | nullable (null for receipts)                         |
| dest_location_id   | uuid FK → locations     | nullable (null for deliveries)                       |
| partner_name       | varchar(255)            | supplier (receipts) or customer (deliveries)          |
| notes              | text                    |                                                     |
| scheduled_date     | timestamp               |                                                     |
| completed_date     | timestamp               |                                                     |
| created_by         | uuid FK → users         |                                                     |
| created_at         | timestamp default now() |                                                     |
| updated_at         | timestamp default now() |                                                     |

### 2.9 `operation_lines`

Individual product lines within an operation.

| Column         | Type                    | Notes                              |
| -------------- | ----------------------- | ---------------------------------- |
| id             | uuid PK                 |                                    |
| operation_id   | uuid FK → operations    | ON DELETE CASCADE                  |
| product_id     | uuid FK → products      |                                    |
| quantity       | integer NN              | quantity planned                   |
| quantity_done  | integer default 0       | quantity actually processed        |
| created_at     | timestamp default now() |                                    |

### 2.10 `stock_moves` (Ledger)

Immutable log of every stock mutation. **This is the audit trail.**

| Column           | Type                    | Notes                              |
| ---------------- | ----------------------- | ---------------------------------- |
| id               | uuid PK                 |                                    |
| operation_id     | uuid FK → operations    | nullable (adjustments may be standalone) |
| operation_line_id| uuid FK → operation_lines | nullable                         |
| product_id       | uuid FK → products      |                                    |
| from_location_id | uuid FK → locations     | nullable                           |
| to_location_id   | uuid FK → locations     | nullable                           |
| quantity         | integer NN              | always positive                    |
| move_type        | enum('in','out','transfer','adjustment') |                     |
| reason           | text                    | e.g. "Damaged", "Vendor return"    |
| created_by       | uuid FK → users         |                                    |
| created_at       | timestamp default now() |                                    |

```ts
// -- schema/operations.ts --
import { pgTable, uuid, varchar, text, integer, timestamp } from "drizzle-orm/pg-core";
import { operationTypeEnum, operationStatusEnum } from "./enums.js";
import { locations } from "./locations.js";
import { products } from "./products.js";
import { users } from "./users.js";

export const operations = pgTable("operations", {
  id:               uuid("id").defaultRandom().primaryKey(),
  reference:        varchar("reference", { length: 50 }).notNull().unique(),
  type:             operationTypeEnum("type").notNull(),
  status:           operationStatusEnum("status").default("draft").notNull(),
  sourceLocationId: uuid("source_location_id").references(() => locations.id),
  destLocationId:   uuid("dest_location_id").references(() => locations.id),
  partnerName:      varchar("partner_name", { length: 255 }),
  notes:            text("notes"),
  scheduledDate:    timestamp("scheduled_date"),
  completedDate:    timestamp("completed_date"),
  createdBy:        uuid("created_by").references(() => users.id).notNull(),
  createdAt:        timestamp("created_at").defaultNow().notNull(),
  updatedAt:        timestamp("updated_at").defaultNow().notNull(),
});

export const operationLines = pgTable("operation_lines", {
  id:           uuid("id").defaultRandom().primaryKey(),
  operationId:  uuid("operation_id").references(() => operations.id, { onDelete: "cascade" }).notNull(),
  productId:    uuid("product_id").references(() => products.id).notNull(),
  quantity:     integer("quantity").notNull(),
  quantityDone: integer("quantity_done").default(0).notNull(),
  createdAt:    timestamp("created_at").defaultNow().notNull(),
});
```

```ts
// -- schema/stock.ts --
import { pgTable, uuid, integer, text, timestamp, uniqueIndex } from "drizzle-orm/pg-core";
import { moveTypeEnum } from "./enums.js";
import { products } from "./products.js";
import { locations } from "./locations.js";
import { operations, operationLines } from "./operations.js";
import { users } from "./users.js";

export const stockLevels = pgTable("stock_levels", {
  id:         uuid("id").defaultRandom().primaryKey(),
  productId:  uuid("product_id").references(() => products.id).notNull(),
  locationId: uuid("location_id").references(() => locations.id).notNull(),
  quantity:   integer("quantity").default(0).notNull(),
  updatedAt:  timestamp("updated_at").defaultNow().notNull(),
}, (table) => ({
  productLocationIdx: uniqueIndex("uq_product_location").on(table.productId, table.locationId),
}));

export const stockMoves = pgTable("stock_moves", {
  id:              uuid("id").defaultRandom().primaryKey(),
  operationId:     uuid("operation_id").references(() => operations.id),
  operationLineId: uuid("operation_line_id").references(() => operationLines.id),
  productId:       uuid("product_id").references(() => products.id).notNull(),
  fromLocationId:  uuid("from_location_id").references(() => locations.id),
  toLocationId:    uuid("to_location_id").references(() => locations.id),
  quantity:        integer("quantity").notNull(),
  moveType:        moveTypeEnum("move_type").notNull(),
  reason:          text("reason"),
  createdBy:       uuid("created_by").references(() => users.id).notNull(),
  createdAt:       timestamp("created_at").defaultNow().notNull(),
});
```

### Phase 4 — Operations Engine (Day 2–3)

This is the **core** of the system. A single unified operations module handles receipts, deliveries, internal transfers, and adjustments.

| #  | Task                                                        | Details |
| -- | ----------------------------------------------------------- | ------- |
| 1  | Create operation (draft)                                    | `POST /api/operations` with `type`, `lines[]` |
| 2  | List operations with filters                                | `GET /api/operations?type=receipt&status=draft&warehouse=...` |
| 3  | Get single operation with lines                             | `GET /api/operations/:id` |
| 4  | Update draft operation                                      | `PATCH /api/operations/:id` — only if status=draft |
| 5  | Cancel operation                                            | `POST /api/operations/:id/cancel` |
| 6  | **Validate operation** (the critical endpoint)              | `POST /api/operations/:id/validate` |
|    |                                                             | This transitions status → `done` and triggers stock mutations: |
|    |                                                             | • **Receipt**: +qty at `dest_location`, write `stock_move(in)` |
|    |                                                             | • **Delivery**: −qty at `source_location`, write `stock_move(out)` |
|    |                                                             | • **Internal**: −source +dest, write `stock_move(transfer)` |
|    |                                                             | • **Adjustment**: set qty, write `stock_move(adjustment)` |
|    |                                                             | All mutations wrapped in a **Postgres transaction**. |
| 7  | Auto-generate reference numbers                             | `REC-000001`, `DEL-000001`, `INT-000001`, `ADJ-000001` |

## 5. API Contract

> **Base URL**: `http://localhost:3001/api`
> **Auth**: Bearer token in `Authorization` header (unless marked 🔓 public).
> **Pagination**: `?page=1&limit=20` on all list endpoints. Response includes `{ data, meta: { total, page, limit, totalPages } }`.
> **Error shape**: `{ error: string, details?: ZodError[] }`

### Zod Validation (shared via `drizzle-zod`)

All request bodies are validated using Zod schemas generated from Drizzle table definitions via `drizzle-zod`. Frontend can import the same Zod types from a shared package for consistent validation.

```ts
// Example: operation creation schema
const createOperationSchema = z.object({
  type: z.enum(["receipt", "delivery", "internal", "adjustment"]),
  sourceLocationId: z.string().uuid().optional(),
  destLocationId: z.string().uuid().optional(),
  partnerName: z.string().max(255).optional(),
  notes: z.string().optional(),
  scheduledDate: z.string().datetime().optional(),
  lines: z.array(z.object({
    productId: z.string().uuid(),
    quantity: z.number().int().positive(),
  })).min(1, "At least one product line required"),
}).refine(
  (data) => {
    if (data.type === "receipt") return !!data.destLocationId;
    if (data.type === "delivery") return !!data.sourceLocationId;
    if (data.type === "internal") return !!data.sourceLocationId && !!data.destLocationId;
    if (data.type === "adjustment") return !!data.destLocationId;
    return true;
  },
  { message: "Missing required location for this operation type" }
);
```
